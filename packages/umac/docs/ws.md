## What can we do with `umac`?

[![HELP]({{const.pkg.repository.url}}/blob/main/docs/public/help.png?raw=true)]({{const.pkg.homepage}})

- Set dialogs
- Set notifications
- Set voice messages
- open files & URLs
- Close apps
- Clear cache
- Install apps
- Change terminal shell
- Add workflows 
- Run scripts
- ...

## 🗝 Prerequisites

- A system based on **DarwinOS**, that is, any **Apple** computer 🍎

## 🚀 Quick start

### JavaScript / TypeScript library

You can also use `umac` as a **JS** / **TS** library directly in your project.

### CLI

Quickly run the command line with:

```bash
npx umac <command> [...flags]
```

### Use Executable

You can download the binary directly from the [releases]({{const.pkg.repository.url}}/releases) section
